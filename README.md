#NBA Game Prediction Project

## Goal

Predict the probability that the home team wins an NBA regular-season
game using only information available before the game begins.

## Initial target

- 1: Home team wins
- 0: Away team wins

## Initial features

- Home-team season win percentage before the game
- Away-team season win percentage before the game
- Home-team last-5-games win percentage
- Away-team last-5-games win percentage
- Home-team average point differential over the last 5 games
- Away-team average point differential over the last 5 games
- Home-team rest days
- Away-team rest days

## Initial model

Logistic regression

## Evaluation

- Accuracy
- Log loss
- Brier score
- Confusion matrix
